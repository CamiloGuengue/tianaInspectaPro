# INTERPRETACION EMPRESARIAL


##### a) MODELO DE NEGOCIO

esto habla de como los datos pueden dar forma y soportar un modelo empresarial,
esto incluye escalabilidad, costos y flexibilidad.

##### b) ACTORES DEL SISTEMA

son todas las entidades que interactuan con el sistema, pueden ser personas, organizaciones o sistemas.

##### c) QUE INFORMACION ESTA ESTRUCTURA?

esta informacion debe tener un esquema fijo, relacion entre tablas. si pueden cambiar, son 
NOSQL.

##### d) QUE INFORMACION ES DINAMICA

cuando cambia constantemente, ya sea por estructura, contenido o volumen.

##### e) IDENTIFICAR INFORMACION CRITICA Y CON TRAZABILIDAD

esta informacion es la que no puede ser modificada mas adelante y debe responder a las siguientes preguntas: ¿QUIEN?,¿QUE?,¿CUANDO?,¿COMO?.
